# Smarfly2 v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a webcam-driven artificial ethology bench where a simple hidden-state fly moves in a real visual stream and three matched observers predict its short future trajectory from visible evidence, with matched-present episodes exposing when history matters.

**Architecture:** The fly and observer are separate subsystems. The fly consumes cheap local visual features and updates three hidden states (fast sensory trace, slow contextual bias, adaptation) before moving; observers receive only visible state plus the same measured world features. Sessions are recorded once and replayed identically into a present-only ridge baseline, a fixed-window ridge baseline, and a compact resident/windowed observer with fast, slow, and cyclic coordinates.

**Tech Stack:** Python 3.10+, NumPy, OpenCV, Tkinter/Pillow for the live GUI, pytest for tests. No pretrained models and no heavyweight ML framework in v0.

**Spec:** `docs/superpowers/specs/2026-09-27-smarfly2-v0-design.md`

## Global Constraints

- One to a few fixed-rule flies only; no GAx evolution in v0.
- Observer receives world evidence plus visible fly behavior and never receives hidden fly state or rule coefficients.
- Hidden fly state is logged only for audit after prediction.
- Inner loop must stay lightweight and run at webcam/video rate; no LLM, diffusion, DINO, or other foundation model.
- Main prediction target is `(dx, dy, dheading)` over a fixed horizon of 8 frames.
- Train/evaluate on contiguous time ranges or separate sessions; never random-frame split adjacent video.
- Every observer arm must score the exact same target frames.
- Live GUI remains usable before fitted models exist.
- Synthetic world exists only as a deterministic test fixture.

## Review Focus

1. **Camera/video frame dropout:** a missing frame must not corrupt fly state or create a malformed record; live loop skips it cleanly.
2. **Angle wraparound near ±π:** target and error calculations must use circular differences rather than raw subtraction.
3. **Short sessions:** fitting must reject sessions too short for horizon/window requirements with a clear error instead of producing singular garbage.
4. **Observer leakage:** serialized/public observer samples must exclude hidden fly-state fields even though audit records contain them.
5. **Replay equality:** all observer arms must consume identical visible samples and target indices; control transforms may alter only history, never the current sample or target.
